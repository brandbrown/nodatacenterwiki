# Internal leads (NOT published)

This directory holds strategic and legal leverage leads generated by the domain
lenses. **Nothing here is published to the public website.** It feeds the internal
digest email to the site-owner list only.

Rules:

- Legal items are **research questions and leads for the Alliance's attorney to vet**,
  never public legal advice.
- Every item should be clearly labeled as AI-generated and pending human review.
- Keep sources attached so a human can verify quickly.

File format: one Markdown file per lead, or dated batch files written by
`agents/analyze.ts`.
